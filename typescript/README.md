# Making Anthropic API Request : Typescript

## Setup

Install dependencies (run once from the `typescript/` folder):

```
npm install
```

## Running a file

```
npx ts-node 001_requests.ts
```

## Files

| File | Concept |
|---|---|
| `001_requests.ts` | Making a basic API request |
| `002_multi-turn-conversations.ts` | Building a multi-turn conversation with a messages list |
| `003_looping_chatbot.ts` | A while loop chatbot with user input |
| `004_system_prompting.ts` | Passing a system prompt to shape Claude's behavior |
| `005_temperature.ts` | Controlling response randomness with temperature |
| `006_response_streaming.ts` | Streaming responses chunk by chunk |
| `d1_1_agentic_loop.ts` | Agentic loop lifecycle with tool use |
